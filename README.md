# 🏨 Noble Nights – Hotel Booking System  

A **full-stack hotel booking system** built with the **MERN stack (MongoDB, Express.js, React, Node.js)**.  
It provides customers with a seamless reservation experience while enabling admins to efficiently manage rooms, bookings, and users.

## ✨ Features  

### 👤 Customer Side  
- Browse available rooms in real-time  
- Book rooms with instant confirmation  
- Secure authentication & authorization  
- Manage bookings and user profile  

### 🛠️ Admin Side  
- Dashboard for managing rooms, users, and bookings  
- CRUD operations for room inventory  
- Monitor reservations and user activity  
- Role-based access  

### 🔒 Security  
- Authentication with JWT  
- Data validation for all forms  
- Secure API endpoints  

---

## 🏗️ Tech Stack  

**Frontend:** React, Tailwind CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Other Tools:** JWT, Axios, REST APIs
